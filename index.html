Keyboard shortcuts

    Alt+N
    New buffer
    Alt+B
    Buffer list
    Alt+L
    Language list
    Alt+Z
    Toggle line wrap
    Ctrl+/
    Toggle comment
    Alt+Up / Alt+Down
    Move line up / down
    Tab / Shift+Tab
    Indent / outdent selected lines
    Enter
    New line, keeping indentation
    Ctrl+scroll
    Change text size
    Alt+/
    Show this help
    Up / Down, Enter
    Move and choose in lists
    Delete / Shift+Backspace
    Delete highlighted buffer (buffer list)
    Esc
    Close lists and help
